<h1>🎓 University System</h1>

Plataforma de gerenciamento acadêmico desenvolvida como trabalho de extensão da disciplina  
<strong>Desenvolvimento de Artefato II</strong>.

O sistema centraliza informações acadêmicas em um único ambiente, permitindo o gerenciamento de:
- Disciplinas
- Notas
- Professores
- Tarefas e avaliações
- Informações da comunidade acadêmica

<h2>Tecnologias</h2>

- Python 3
- Django
- Tailwind CSS
- HTML5
- SQLite
- Poetry (gerenciamento de dependências)

<h2>Funcionalidades</h2>

- Login com Google
- Visualização de disciplinas cadastradas
- Consulta de notas
- Gerenciamento de tarefas e projetos acadêmicos
- Centralização de informações e eventos da comunidade universitária
- Personalização de perfil
- Painel administrativo via Django Admin

<h2>Dependências</h2>
